# Web Shop

Computer storefront: catalogue, search, sort and a cart. React SPA with routes for products and a mock account. Catalogue state and cart live in `localStorage`.

**Live:** [albert-braun.github.io/Web-shop](https://albert-braun.github.io/Web-shop/)

## Stack
- React 19
- Vite
- React Router
- Tailwind CSS
- `localStorage` (account + cart)
- GitHub Pages

## What’s in the UI
- Keyword search over the catalogue
- Sort / filter by price and specs
- Cart: add, remove, quantities, total
- Mock sign-in and a saved local profile

## Run locally
```bash
npm install
npm run dev
```
