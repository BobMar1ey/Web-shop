# Web Shop

Computer storefront: catalogue, search, sort, and a cart. React SPA with product routes and a mock account. Catalogue and cart live in `localStorage`.

**Live:** [albert-braun.github.io/Web-shop](https://albert-braun.github.io/Web-shop/)

## What it does

- **Search** — keyword lookup over the catalogue
- **Sort / filter** — price and specs
- **Cart** — add, remove, quantities, total
- **Account** — mock sign-in and a saved local profile

**Stack:** React 19 · Vite · React Router · Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```
