## Tech Stack
* **Frontend:** [e.g., React]
* **Build Tool:** Vite 7
* **Routing:** React Router 7
* **Styling:** [e.g., Tailwind CSS / CSS3]
* **State & Storage:** `LocalStorage` (used for user account and cart persistence)
* **Deployment:** GitHub Pages

## Features
* **User Account:** Mock authentication and local user profile persistence.
* **Search:** Real-time keyword search across the computer catalog.
* **Sort & Filter:** Catalog sorting by price and key specifications.
* **Shopping Cart:** Add/remove items, update quantities, and instant total price calculation.
